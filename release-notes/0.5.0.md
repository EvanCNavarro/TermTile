# TermTile 0.5.0

- Added a fifth Session tint state, for sessions running a long autonomous loop. Those alternate
  between working and waiting for the next scheduled cycle, so they used to flicker between colours
  — and worse, during the waits they went **green**, meaning finished, while they were mid-task and
  about to pick up again. A looping session now holds one **purple** for the whole loop.
- A loop declares itself rather than being guessed at. `scripts/loop-flag.sh set` marks the session
  and `clear` releases it; the mark carries the session's process id, so a loop that is killed
  cannot leave a window stuck purple — TermTile ignores and removes the stale mark by itself.
- Amber still wins over purple: a loop that is waiting on your answer needs you now.
