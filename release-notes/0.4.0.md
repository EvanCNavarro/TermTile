# TermTile 0.4.0

- Added a fourth Session tint state. A session that has answered but still has a background shell
  running now goes **blue** instead of green. Green means finished; blue means it will come back to
  life on its own without you.
- This closes a case where a window went green while it was still waiting on a deploy, with shells
  running — green invites you to act on a session that is not done.
- Both agents are recognised: Claude Code's shell count and Codex's background-terminal count.
- Known limit: if the session's footer is hidden behind a scrolled-back view, TermTile cannot see
  the count and the window stays green. An agent that says it is waiting on something without
  leaving a shell running is also invisible to this.
