# TermTile 0.3.1

A fix for the menu panel's appearance.

- Fixed the menu panel showing empty bands of window material above and below its content. The
  panel's window keeps the tallest height it has ever needed, so once the menu had shown a taller
  state — an extra terminal listed under Session tint, say — the shorter content afterwards was
  left floating in the middle of it. The panel now fills its window from the top, so no gap shows.

> **CORRECTION (2026-09-24).** The claim above is false: this fix did not work, and the release note
> should not have said it did. The extra height is OUTSIDE the SwiftUI view — the bands are
> transparent window, not window material behind a too-small background — so filling from the top
> could not reach it. 0.3.2's follow-up was inert for a different reason. Fixed in 0.5.2; the
> measurements are on EvanCNavarro/TermTile#44.
