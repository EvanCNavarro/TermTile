# TermTile 0.3.0

This release adds **Session tint**: an optional feature that colours each terminal session by what
its agent is doing, so a glance at the grid tells you which window is finished, which is still
working, and which is waiting on you.

- Added **Session tint**, off by default and switched on from the menu. Idle sessions go green,
  sessions waiting on your answer go amber, and working sessions stay at their normal background.
- Added a **Ready shade** choice of Standard or Bold, for displays or lighting where the standard
  green does not read strongly enough.
- Session tint reports the sessions it could **not** colour, and why — a window that shares its
  folder with another terminal, or one whose state is not recognised yet. Sessions it did colour are
  summarised as a count rather than listed, since the colour already says what they are.
- **Session tint is iTerm2 only, and needs iTerm2 3.3 or newer.** WezTerm ignores the escape
  sequence TermTile uses to set a background colour. Tiling works with both terminals, as before,
  and has no version requirement.
- Session tint reads more than tiling does — each session's visible text, and the environment of the
  agent process — and the menu says so where you turn it on. Nothing leaves your Mac, and it needs
  no permission beyond the Accessibility grant tiling already uses.
- Polished the update-available indicator and the Accessibility permission-recovery flow, and
  centred the menu bar glyph in its badge.
