# TermTile 0.6.1

A way out when Settings shows TermTile allowed but TermTile still says it isn't.

- **"Allow Accessibility" now leads to a fix when allowing doesn't take.** If another copy of TermTile was
  once allowed on this Mac, System Settings can show TermTile switched on while the copy you're running is
  still not allowed, and switching it on again does nothing. After you've been sent to Settings once and
  TermTile is still not allowed, the notice now offers **Reset & Open Settings**, which clears the old
  entry so you can allow this copy. Before, that button only appeared for a copy that had worked before.

- **Local builds no longer take over the released app's permission.** Builds that aren't signed with the
  release certificate now get their own identifier (`dev.ecn.apps.termtile.local`), so running one can't
  leave the released app's Accessibility entry pointing at the wrong copy. This only affects people who
  build TermTile themselves.
