# TermTile 0.6.0

Other programs can now ask TermTile to rearrange.

- **`open -g termtile://rearrange` does what the Rearrange now button does.** A script or tool that
  opens or closes terminal windows can tidy the grid afterwards without anyone clicking the menu.
  `-g` keeps TermTile in the background.

- **Only that exact URL is accepted.** Any app or web page can open a custom URL, so TermTile ignores
  every other command and any parameters. A rejected URL is logged without its contents.

- **Several requests in a row cost one extra rearrange, not one each.** Requests that arrive while a
  rearrange is running are combined into a single follow-up run, which still includes the last
  window opened.

- **Fixed: the grid now fits the screen after its size changes.** TermTile read the screen's size once,
  when it launched, so after a resolution change (a remote-desktop session, a different monitor) every
  rearrange sized windows for the old screen. It now reads the size each time it rearranges.

Rearranging still needs Accessibility, as before.
