# TermTile 0.3.2

A second, corrected fix for the menu panel's appearance.

- Fixed the menu panel leaving empty gaps above and below its content. The panel's window keeps the
  tallest height it has ever needed, so once the menu had shown a taller state the shorter content
  afterwards was left floating in the middle of it. The window now shrinks back onto its content
  when the menu is opened.
- **0.3.1 claimed this was fixed and it was not.** That release changed the wrong thing — it tried
  to make the content fill the extra space, but the extra space sits outside the content entirely,
  so nothing changed on screen. That change has been removed.
